### Execution path

```
TurkuFfmpegClipGenerationHarness(runner, clipGenerationEnabled=true)
  → TurkuFfmpegLocalDevProcessRunner.generateClip(request, binaryPolicy)
    → gate.evaluate() → ALLOWED
    → executeClipGeneration(request)
      → File.createTempFile("turku_internal_clip_", ".mp4")
      → ProcessBuilder("ffmpeg", "-y", "-f", "lavfi", "-i", "testsrc=...", ...)
      → Process.start() → exit 0 → file.length() > 0
      → PROCESS_COMPLETED_SAFE → VERIFICATION_PASSED ✅
```
